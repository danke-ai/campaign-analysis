# 数据字典 · 国庆好物节活动复盘

## 1. 分析范围

- 活动：`aid = 10001` 国庆好物节，2080-09-28 ~ 2080-10-11（14 天）
- 对照期：2080-09-14 ~ 2080-09-27（14 天）
- 平台：某电商 App（脱敏）

## 3. 口径定义

| 指标 | 定义 | 本次结果 |
|---|---|---:|
| 曝光人数 | `COUNT(DISTINCT userid)`，`click_or_expose='expose'` | 22,572 |
| 曝光次数 | `COUNT(*)`，同上 | 112,338 |
| 点击人数 | `COUNT(DISTINCT userid)`，`click_or_expose='click'` | 1,907 |
| 点击次数 | `COUNT(*)`，同上 | 2,282 |
| 点击率（宽松） | 点击人数 ÷ 曝光人数 | 8.45% |
| 点击率（严格） | 既曝光又点击人数 ÷ 曝光人数 | 6.66% |

| 达标人数 | 同上，达标表 | 396 |

| 整体转化率（曝光→达标） | 达标人数 ÷ 曝光人数 | 1.75% |
| 日均活跃次数 | `AVG(CAST(activenum AS DECIMAL))` | — |

## 4. 数据质量与处理规则

| 问题 | 数量 | 影响 | 处理规则 |
|---|---:|---|---|
| 画像表重复用户 | 11 个 userid，各 2 行 | JOIN 后参与人数 489 → 495 | 保留 `createday` 最新的一条 |
| 只点击、无曝光 | 403 人 | 宽松点击率偏高，漏斗低估触达 | 报告注明，提供严格口径 |
| 达标重复 | 413 行 / 396 人 | 行数 ≠ 人数 | 漏斗一律使用 DISTINCT |
| 空值 | 0 | 无 | 已验证 |
| 日期格式 | 全部 10 位 ISO | 字符串可直接比较日期 | 已验证 |
| 主键 / 索引 | 无 | 数据库不防重 | 清洗靠 SQL |
| activenum 类型 | varchar（如 `'1.0'`） | MIN/MAX 会按字符串比较出错 | 计算前 CAST |

## 5. 已知局限

1. 参与用户非随机分组，存在自选择偏差，活动效果只能测算、不能直接因果归因。
2. 埋点不全：403 个用户只有点击无曝光，漏斗低估真实触达。
3. 单活动、单平台、14 天窗口，数据已脱敏，结论外推有限。
4. 曝光-参与相关性为线性回归，20 万曝光属于超出样本范围的外推，仅作粗估。
